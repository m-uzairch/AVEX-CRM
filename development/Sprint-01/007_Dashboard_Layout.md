# Sprint 01 - Task 007

# Dashboard Foundation & Core Layout

Status: Not Started

Priority: High

Estimated Time: 6–8 Hours

---

# Objective

Build the main dashboard experience for AVEX CRM.

This task should create the application's primary workspace after a user logs in.

Use placeholder data only.

Do not connect to the database or implement business modules.

---

# Requirements

Create the complete dashboard layout that will serve as the foundation for every future module.

The dashboard should feel clean, modern, responsive, and fast.

Use the design system created in Task 002.

---
